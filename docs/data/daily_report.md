> 在实现生态社会成果（即社会福祉与环境可持续性的共同实现）方面，政府发挥着核心作用。 然而，关于政府支出与生态社会成果之间关系的实证证据仍然有限。本研究利用投入产出分析和回归分析，考察了2005年至2019年间116个国家政府支出、人类需求满足度与碳影响之间的关系。 为了体现全球气候正义，我们根据各国在全球剩余碳预算中的公平份额，对碳强度（CO2e/美元）进行了调整。这些经过公平性调整的碳强度既反映了支出的碳效率，也体现了各国相对于其公平碳预算的地位。 我们发现，较高的政府支出通常与更好的社会成果相关，尽管在较高支出水平下边际收益会递减，且取决于支出的构成。 教育与休闲、社会保护以及公共行政领域的支出与更佳的社会成果相关，且其经公平性调整后的碳强度相对较低。相比之下，与工业相关的政府支出始终表现出较高的碳强度，这表明可能存在碳锁定现象。对于大多数支出类别而言，社会成果越好的国家，其碳强度往往越低，但住房领域是一个显著的例外。 尽管公共秩序和国防支出对碳排放产生显著影响，但其与较低的社会成果相关。在包括教育与娱乐、卫生与环境以及社会保护在内的关键福利领域，政府支出带来的生态社会成果优于家庭支出，这表明公共和集体供给具有优势。
