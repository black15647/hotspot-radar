- **热度**：100.0

> 森林覆盖范围和森林管理在塑造生物多样性对气候和土地利用变化的响应方面都至关重要。然而，尽管土地利用模型在区分不同森林管理措施方面已取得进展，但生物多样性影响模型通常仍将受管理的森林视为一个汇总类别。这限制了我们评估未来情景下不同管理措施之间的转变如何影响生物多样性的能力。 我们通过将生物多样性模型GLOBIO与基于代理的土地利用模型CRAFTY-EU耦合，解决了这一问题。GLOBIO模拟了物种平均丰度（MSA）对生物多样性丧失驱动因素的响应变化。 CRAFTY-EU 根据社会需求以及社会经济和生物物理适宜性，分配土地利用类型，其中包括六种具有不同木材采伐强度的森林管理实践。 我们整合了GLOBIO模型中的气候变化、土地利用以及更新的森林管理MSA估算结果，以评估三种社会经济与气候情景（SSP1-RCP2.6、SSP3-RCP7.0和SSP5-RCP8.5）下的生物多样性结果。 只有在农业弃耕面积较大且气候影响适中的情况下，森林扩张才能部分缓解生物多样性丧失。这种效应在SSP1-RCP2.6情景下最为显著，在SSP5-RCP8.5情景下较弱（因气候损失占主导），而在SSP3-RCP7.0情景下则基本不存在（因弃耕面积有限且森林退化程度较轻）。 在所有情景中，向集约化森林管理转型均导致MSA下降，这表明仅靠森林扩张并不能保证带来生物多样性效益，特别是在管理集约化程度加深和气候变化加剧的情况下。 那些在促进森林恢复的同时避免管理强度的土地利用和林业政策，可以缓解生物多样性损失，但不太可能弥补由气候变化导致的严重衰退。此类政策与欧盟的《自然恢复条例》相一致，该条例提议到2030年种植30亿棵树并恢复20%的土地。要成功实施该条例，需要考虑……

- **来源**：Environmental Research Letters
- **热度**：96.8
- **发布时间**：2026-09-08T23:00:00+00:00
- **关键词**：生物多样性, 生态系统

> 全球森林及其所蕴含的生物多样性，为人类福祉提供了多种文化生态系统服务。然而，人类与森林之间的互动随着更广泛的社会和环境变化而演变，这引发了一个问题：与森林文化生态系统服务相关的价值是否随时间推移而发生了变化。 为探讨这一问题，我们对1980年至2019年这四十年間收集的137项经济估值研究（共705个观测值）进行了全球性荟萃分析。研究结果未发现旅行成本、条件估值、选择实验或享乐定价估算存在具有统计学意义的时序趋势。 同样，仅针对休闲活动的子样本也未显示货币价值随时间存在统计学上显著的趋势。尽管研究涵盖了多种文化生态系统服务类别和森林类型，但现有证据基础存在向高收入国家倾斜的偏倚，且估值研究仍高度集中于与森林的休闲互动，而精神与象征性互动则极少被量化。 这些知识缺口限制了我们量化全球森林文化生态系统服务货币价值的能力。尽管我们未发现人们对森林文化生态系统服务所赋予的价值存在时间趋势的证据，但模型中观察到的显著异质性及特定方法模式表明，在进行效益转移时不应假设其具有时间稳定性。 鉴于这些发现，在环境决策中应用效益转移方法时，应考虑方法论异质性和情境差异。中低收入国家相关研究匮乏，加之研究重点过度集中于休闲活动，凸显了开展更广泛且地域多元化的估值研究的必要性。弥补这些空白有助于支持采取更具情境敏感性的方法
