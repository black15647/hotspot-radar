> 生物入侵和碳封存是当今许多土地管理决策的重要依据。然而，入侵与自然气候解决方案（NCS）——即旨在维持或增加土地碳汇的举措——之间的交集，无论是在入侵研究文献还是气候减缓文献中，都尚未得到充分关注。 因此，我们回顾了植物入侵如何影响自然气候解决方案，反之亦然，重点探讨了通过避免栖息地转化、生态修复、森林和农田管理、农林复合经营以及优化放牧所带来的减排和碳移除效应。 我们发现，尽管在某些情况下入侵植物会增加碳储量，从而产生生物多样性与气候减缓之间的权衡，但植物入侵可能会干扰自然气候解决方案的快速实施，并降低许多系统中碳储存的持久性。 与此同时，研究发现，若干自然碳储量措施可增强群落对入侵的抵抗力/韧性，特别是在森林中，从而抑制入侵物种在这些系统中的扩散。 这些动态表明，NCS 与入侵之间存在正反馈循环：NCS 有助于控制入侵，而成功的入侵控制反过来又促进了 NCS 的进一步实施。只要 NCS 项目获得用于持续管理入侵物种的资源，这种反馈就能加速陆地碳储量的增长，并为生物多样性带来协同效益。 我们重点指出了需要进一步研究的领域，包括如何利用气候行动的金融机制来克服入侵物种引发的实施障碍。
