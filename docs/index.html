透明热度算法 v3.0

基础分 base = 权威度(0-18) + 话题分(0-18) + 事件共振(0-18) + 信息量(0-16)
时间衰减 T = 0.35 + 0.65 × e(−hours/48)
原始分 raw = base × T × 信息密度 × 重复惩罚
展示分 = 40 + 60 × (1 − e(−raw/20))

  • 权威度（0-18）：谁在说。按 18 × √(来源权重 − 1) 映射，开方用于压缩高权重端的优势、避免少数顶刊源垄断前列，且没有常数底分。
  • 话题分（0-18）：说的是不是当下有价值的题。IDF 稀缺度（0-12）+ 当日聚集度（0-6）+ 零命中兜底（3），越具体的环境词贡献越大，"环境/污染"等泛词自动降权。
  • 事件共振（0-18）：多少家不同媒体在报道同一件事。同一事件按标题重叠系数聚类，统计独立报道方数量，反映真实关注热度。
  • 信息量（0-16）：说得多具体。量化信息 + 具体主体 + 研究信号 + 可读描述，中英文判据对等，不依赖 AI 摘要。
  • 时间衰减：保留 35% 长尾、48 小时半衰期，兼顾新闻时效与知识长期价值。
  • 信息密度：国家级主体与规范性文件体裁加分，地方行政宣传稿降权。
  • 重复惩罚：同一事件被多个来源报道时，仅保留最高分条目，其余 ×0.6，避免刷屏。
  • 展示分：绝对标定，同一个 raw 在任何一天都得到同一个分，因此热度分可跨日比较；"今天没什么热点"会如实显示为整榜分数偏低，而不会像逐日百分位那样必然占满 40–100 两端。
  • 中英双语对齐：英文标题会通过英文别名或其中文译文参与关键词匹配，因此英文来源同样能获得话题分与事件共振分；同一事件的中英报道也会被识别为重复。
